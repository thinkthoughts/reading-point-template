# Reading Point Template (RP_TEMPLATE)

## Purpose

RP_TEMPLATE specifies one Reading Point.

Each Reading Point describes one engineering transition.

---

## Identity

Each Reading Point specifies:

- reading point
- stage
- version
- status

---

## Engineering Context

Each Reading Point specifies:

- engineering objective
- engineering statement
- repository grammar
- forward context

---

## Dialogue

Each Reading Point specifies:

- title
- first dialogue object
- second dialogue object
- supporting context
- engineering statement

---

## Generated Bundle

NB_TEMPLATE compiles each Reading Point into:

- dialogue figure
- accessibility text
- README
- metadata
- manifest
- notebook bundle
